# Bundled data (SYNTHETIC)

Every CSV in this directory is **synthetic**. The files were generated by
`scripts/generate_synthetic_data.py` with a seeded geometric Brownian motion. They are
not real market prices. They exist so the API works offline and the tests are
deterministic.

File naming: `<SYMBOL>_<interval>.csv` with columns
`open_time,open,high,low,close,volume` (`open_time` in UTC, ISO-8601). Lines that start
with `#` are comments.

To rebuild them:

```bash
python scripts/generate_synthetic_data.py
```
